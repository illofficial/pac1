# Premium Audio Converter

Браузерный энхансер аудио для музыкальной школы: загружаешь файл (или
вставляешь прямую ссылку на .mp3/.wav) — получаешь WAV с фирменной
обработкой, максимально близкой к личной Ableton-цепочке автора (True Iron
→ bx_enhancer → Multiband Compression → Kazrog MHB Green AMP mode →
FabFilter Pro-L 2).

**Полностью клиентский инструмент.** Вся обработка идёт в браузере через
Web Audio API — сервера нет и не требуется. Открой `index.html` откуда
угодно (двойным кликом, через GitHub Pages, любой статический хостинг) —
и всё работает.

**Скачивание с YouTube не поддерживается и не будет добавлено.** Это
осознанное решение (условия использования YouTube + риски публичного
исполнения в контексте музыкальной школы) — при вставке ссылки на
YouTube-страницу инструмент явно откажет и объяснит, что нужно прямую
ссылку на аудиофайл или загрузку файла вручную.

## Файлы

- `index.html` — весь прототип: разметка, стили (Pac-Man/CRT эстетика,
  Press Start 2P + VT323), UI-логика и встроенная копия DSP-цепочки в
  `<script id="dsp-src">`.
- `mastering_chain.js` — тот же DSP-модуль отдельным файлом, для
  независимой проверки синтаксиса и разработки. **Должен оставаться
  побайтово идентичен** блоку `<script id="dsp-src">` внутри `index.html` —
  при любых правках синхронизируй оба места.

## Жанровые профили

Soul/Funk (по умолчанию), Universal, EDM/House/Trap, Rap/Hip-Hop, плюс два
"характерных" режима — Vinyl и Tape/VHS.

## Формат выдачи

WAV, 24-bit, частота дискретизации исходника.

## Разработка

```bash
node --check mastering_chain.js   # синтаксис DSP-модуля отдельно
```

Перед коммитом сверяй встроенный `<script id="dsp-src">` в `index.html` с
`mastering_chain.js` — они должны совпадать один в один.
